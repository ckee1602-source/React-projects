# E-commerce Website 
🔴This is an e-commerce website built using HTML, CSS, JavaScript, React.js, Node.js, Vite, and Git, featuring dynamic product listings, add-to-cart functionality, and a fully responsive user interface. The application includes a complete checkout flow with order review and price calculation, along with real-time product updates through efficient state management, DOM manipulation, and event handling. It also integrates React Testing Library with Jest DOM for component testing to ensure UI reliability and correctness.

## Features
🛍️ Dynamic Product Listings – Products are displayed dynamically using JavaScript for easy updates and scalability.

🛒 Add-to-Cart Functionality – Users can add, update, or remove items from the cart with real-time UI updates.

💳 Checkout Page – Complete checkout interface with order summary and user-friendly navigation.

💰 Price Calculation – Automated calculation of subtotal, tax, and total amount based on cart items.

📆 Review Order Page – Includes delivery date selection, item update options, and delete functionality.

📦 Orders Page – Displays previously placed orders with essential order details.

🚚 Tracking Page – Allows users to track the status and delivery progress of their orders.
